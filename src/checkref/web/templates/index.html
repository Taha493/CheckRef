How it works

Three steps, no account.

1

Upload

The thesis or synopsis as PDF or Word. Only the text is read; images are ignored.

2

Check

Every reference and citation is compared with the APA 6th Edition guidelines and with each other.

3

Report

A report with each problem, the rule it breaks and its source, plus a corrected reference list.

03

What it checks

Format only: authors, order, punctuation, italics and capitals, as the guidelines set them out.

04

Good to know

Private by design

Your file is deleted as soon as the check finishes. The report is deleted once the PDF report is downloaded, when you press Delete now, or after {{ settings.expiry_min }} minutes at the latest.

Two levels

Error breaks a rule of the guidelines. Needs review means CiteSure could not decide, so please look at it yourself.

Every rule has a source

Each problem names the rule it breaks and quotes the guide, with a link to the page.

Format only

CiteSure does not check that a source exists or that its details (authors, year, pages) are true.
